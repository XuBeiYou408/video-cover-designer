# 🎬 Video Cover Designer (科技数码视频封面设计引擎 · 逐层步进积木版)

这是一个为 Antigravity / WorkBuddy / Claude Code / Cursor / Agent 生态打造的**科技数码品类、全场景高点击率视频封面生成 Skill**。

系统精准确立并严格支持**四大核心风格**：
1. **【1. 微机风格】**（真人主持出镜实测与工作流 · 30套样本深度优化）
2. **【2. 纯硬件宣传 / 拆解与旗舰PK】**（无真人出镜 · 芯片微距/拆解/旗舰PK）
3. **【3. 电影级深度社论】**（专访与播客 · 人像100%绝对零篡改 · 伦勃朗光与双引号金句）
4. **【4. 纯数据报道类型】**（零图片素材 · 静默抓取链接 · 3D破顶能量柱与全息星核）

---

## 🌟 2.0 积木组装重大升级特性

- **🧱 逐层步进积木搭建（Layer-by-Layer Assembly）**：从过去的“大模型随机黑盒抽卡”，进化为 4 层递进式装配（场景底座 → 主体与道具 → 文字排版与字体 → 次级符号与点缀）。
- **🎲 每层 5 维多样化组件矩阵（5-Dimensional Options）**：每一层均输出 5 个（A/B/C/D/E）不同维度方向、深度咬合文案逻辑的创意构件。
- **📐 九宫格排版自由定位（Nine-Grid Positional Placement）**：每层组件均允许用户自由指定画幅坐标（TL/ML/BL/TC/MC/BC/TR/MR），并强制避让右下角 BR 时长码。
- **📊 累积排版线框图即时反馈（Live Layout Wireframe Feedback）**：每选定一层，系统即刻渲染当前层级叠加后的 ASCII 排版蓝图，核验无误后再推进下一层。
- **🔤 30 套生产级素材字体语法（Font Pairing & Kerning）**：提炼紧凑几何无衬线、撕纸干刷破锋体、高压力量粗黑、黑墨反转等成熟字形矩阵与负字距微排版规范。
- **🚀 双轨工业级交付协议（Dual-Track Zero-Typo Delivery）**：
  - **Track A**：一体化 AI 高精度成片；
  - **Track B**：100% 绝对零错字工业底图 + 矢量排版图层（SVG/CSS/PNG 代码），可在剪映/PS/Figma 中一秒对齐贴合。
- **🔒 真实垫图路径强校验（Anti-Misrouting Protection）**：严禁误取用户发来的对话截图或说明图，100% 锁定真实人像/硬件原图路径，杜绝假脸退化。

## 🔒 核心红线一：【基于用户原图修改强绑定协议】

**在生成提示词（Prompt）时，必须向大模型施加强制约束：必须严格基于用户上传的原图进行增量修改与重构，严禁抛弃原图凭空捏造全新主体！**

- **1. 微机风格（真人实操）**：100% 锁定用户原图中的五官面貌、发型、骨骼比例与真实肤质，**绝对禁止生成随机 AI 假人脸或网红脸**；仅做姿态融合与冷暖轮廓光剥离；
- **2. 纯硬件宣传 / 拆解与旗舰PK（无假人）**：100% 忠实保留原图硬件真实外观结构、接口布局、电路特征与品牌 Logo，**绝不替换为凭空幻觉的其他产品**；
- **3. 电影级深度社论（100% 绝对零篡改）**：嘉宾原图面容、眼神表情、发型胡须与西装衣着 **100% 绝对零修改**，仅调整背景为电影级暗调虚化与伦勃朗光；
- **4. 纯数据报道类型（无图直驱）**：静默提取网页文章与表格，若用户提供跑分截图则 1:1 实体化复刻为 3D 发光柱。

---

## 🔒 核心红线二：【物理级逐层强停机门禁（Hard Breakpoint · 严禁抢跑）】

为避免盲目生图浪费 67% 配额，严格执行**逐层物理断点交互**：
1. **每层选择强制挂起**：输出某层的 5 组差异化方案后，**当前回复必须立即停止（STOP）**！
2. **严禁越层跳步**：绝对禁止在用户未确认前擅自预设后续层级或直接调用生图工具；
3. **线框核验与双轨交付**：选定后即刻渲染累积线框图，全图 4 层拼装完毕经终审后，按用户意愿触发 Track A 一体化成片或 Track B 无字底图。
